Verified Security & Data Governance

Vellakshya Privacy Policy & Data Sovereignty Guarantee

Effective Date: November 2026 • Version 2.0.0 • Lead Architect: Giri Manohar Vemula

1. Local-First Architecture (Zero Network Egress)

Vellakshya is engineered as a privacy-first document workstation. All standard document manipulation features—including PDF merging, page splitting, rotation, margin cropping, and client-side font-matching text replacement—execute directly inside your local web browser session via WebAssembly and HTML5 Canvas.

The F13 Privacy Gate: Under default settings, the "Allow External Cloud AI" privacy gate is strictly disabled. When disabled, all summarization, spatial retrieval, and keyword analytics run in-process using local deterministic extractors with zero external network transmission.

2. Ephemeral In-Memory Storage & Automated Retention TTL

When documents are processed via our serverless API for server-side layout parsing or vector search:

  • Transient In-Memory Store: Documents are stored strictly in volatile, transient memory buffers.
  • 1-Hour Retention TTL: In accordance with our security benchmark (F12), all transient document sessions automatically expire and are permanently purged after 3600 seconds (1 hour).
  • No Model Training: Neither user documents nor extracted text are ever used to train machine learning models.

3. Cryptographic Governance & Client-Side Security

For sensitive workflows, Vellakshya integrates client-side AES-256-GCM encryption, ensuring documents are sealed with user-defined keys before any persistence. Document audit manifests are verified via asymmetric Ed25519 digital signatures to prevent tampering.

4. Cookieless Operation & Telemetry

Vellakshya does not use tracking cookies, advertising identifiers, or invasive third-party analytics trackers. Workstation preferences (such as light/dark theme and sidebar collapsed state) are stored exclusively in your browser's private localStorage. Our telemetry client strictly honors the browser's Do Not Track (DNT) setting.

5. Contact & Governance

For data governance inquiries or technical audits, refer to our official open-source repository at GitHub (ManoharVit/Vellakshya) or reach out via LinkedIn.
